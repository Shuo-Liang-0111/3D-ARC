# RF-10 三项安全检查与侧墙开窗 · rf10-window-v5

## 行为

选关 RF-10（路由 rf12）只要求三项操作：开窗、关燃气炉、关燃气总阀。
新窗初始关闭；用户已明确确认任务方向为开窗。
三项完成且最后一个动作恢复站立后直接通关，无读检查单、移抹布、开油烟机或入口确认前置。
仍须先关炉头，再关总阀。任务计数、开始提示和完成提示同步更新为三项。

水槽上方原窗保留为固定窗。东侧空墙新增推拉窗，窗洞宽 1.35 m、高 1.25 m，
下沿 0.85 m，把手高 1.15 m；前方无台面。
三关共用新版建筑、碰撞和窗户资产。第一视角显示天花板，第三视角隐藏。
其他两关规则保持不变，包括 RF-10-3 的烧水窗口和 60 秒灭火期限。

窗扇手动交互由实际手部接触触发，随后沿轨道连续滑动 0.56 m。
只有手持续处于允许接触误差内才推进窗扇；整个行程完成后提交开窗状态。
新把手是移动窗扇子节点；墙体与独立碰撞模型都留有真实开口，
保留窗下墙对机器人的阻挡。未修改机器人、相机或共享运动合同。

## 资产

复用已有精修窗的铝框、胶条、玻璃和轨道，通过 Blender 精确加工墙洞并增加低位金属拉手。
无需新生成资产。源码工具为 tools/rf10-window-assets.py。
运行时资产目录 public/local-assets/levels/rf12/window-v5：
kitchen-environment.glb、kitchen-collision.glb、sliding-window.glb。
大资产留在授权服务器，不进入 Git。

## 实测

- 35 项状态机、共享玩法、GLB 几何和局部碰撞测试通过。
- 正式浏览器定点验收：三项操作连续成功，仅 3 次交互，
  窗户打开、燃气炉关闭、总阀关闭，complete=true、settling=false。

  接触误差：推窗终点 2.77 cm、炉头 0.28 mm、总阀 0.27 mm。
- 实际查看第三视角侧窗和动作、第一视角手握拉手与窗扇滑动、完成弹层。
  中段画面使用明确的 QA 推窗停帧；窗扇与手均由正式动画推进，
  未直接设完成状态。图像保留于本次浏览器工具记录，未另导出截图文件。
