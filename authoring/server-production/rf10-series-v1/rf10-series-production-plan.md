# RF-10 厨房三关生产方案

## 路由与场景

- 用户关卡：`RF-10`、`RF-10-2`、`RF-10-3`
- 内部路由：`rf12`、`rf12-2`、`rf12-3`
- 共享场景：同一套中国城市家庭厨房、柜体、冰箱、灶台、水槽、窗、入口和碰撞代理。
- 机器人合同：沿用 G1 EDU2、D435、共享运动和 F 键互动，不修改模型、骨骼、尺寸或控制映射。
- 视角：第一人称可抬头看到天花板和灯具；第三人称隐藏天花板视图层。

## 任务状态

### RF-10

保持中等难度的五项厨房安全检查：检查单、燃气旋钮、油烟机、湿抹布、窗户、燃气总阀和入口确认。

### RF-10-2

简单任务只处理一件物品：读取提示 → 拿起食用油瓶 → 放到备餐台 → 入口终端确认。无倒计时和着火状态。

### RF-10-3

高难度只执行烹饪链：放置平底锅 → 开启油烟机 → 开启炉头 → 在 55–65 秒内关火。少于 55 秒会重置烹饪并重新计时；超过 65 秒进入厨房着火状态，玩家必须拿起灭火器灭火，随后重新开启油烟机、炉头并重新计时。成功关火后任务完成。

## 资产

- 共享 RF-10 厨房 Cardinal 环境、固定设备和碰撞资产。
- RF-10-2 的食用油瓶使用运行时程序模型，底部落地并与任务坐标对齐。
- RF-10-3 的平底锅使用运行时程序模型，灭火器复用已验收 Cardinal `fire_safety_station.glb`；GLB 失败时使用同尺寸程序后备模型。
- 火焰和烟雾是运行时表现层，不写入碰撞状态。
