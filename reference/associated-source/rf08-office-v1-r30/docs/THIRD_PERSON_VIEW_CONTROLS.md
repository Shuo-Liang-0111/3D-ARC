# ARC 操控台与第三视角鼠标控制

## 目标

统一 ARC 游戏操控界面的交互方式，并让第三人称视角可以直接通过鼠标完成选中、缩放和环绕观察，同时保持各关卡任务 UI 与资源条逻辑不变。

## 操作方式

- 点击第三视角画面：选中第三视角，并显示高亮边框。
- 鼠标悬停第三视角画面：显示可交互状态。
- 滚动鼠标滚轮：拉近或拉远第三人称相机。
- 按住鼠标中键拖动：水平或垂直旋转第三人称相机。
- 松开中键、指针取消、失去捕获或窗口失焦：立即安全结束拖动。

双视角横屏模式只在右半屏响应第三视角操作；双视角竖屏模式只在下半屏响应。第一视角区域不会触发第三视角缩放或旋转。

## 相机约束

- 缩放范围：`0.35` 至 `2.6`。
- 俯仰角范围：`12°` 至 `86°`。
- 滚轮缩放采用指数变化，使近距离和远距离调整都保持平滑。
- 中键拖动使用指针捕获，避免拖出画面后产生卡住状态。

## 界面反馈

- 第三视角标题增加“滚轮缩放 · 中键旋转”提示。
- 悬停、选中和拖动分别通过 `data-third-view-hovered`、`data-third-view-selected`、`data-third-view-dragging` 状态驱动视觉反馈。
- 横屏双视角高亮右半屏，竖屏双视角高亮下半屏，单第三视角高亮整个画面。
- ARC 操控面板继续提供视角切换、移动、转向、D435 抬头/低头、互动、重置和紧急停止操作。

## 实现文件

- `operator-console.css`：统一操控台布局、第三视角命中区域、高亮状态和拖动光标。
- `game/operator-controls.js`：操控面板按钮、按住/释放、状态同步和停止输入逻辑。
- `game/third-person-view-controls.js`：第三视角命中测试、滚轮缩放、中键旋转和指针生命周期管理。
- `tests/operator-console.test.mjs`：操控面板输入与状态测试。
- `tests/third-person-view-controls.test.mjs`：横竖屏命中、缩放边界、点击选中和中键旋转测试。

`index.html` 与 `game/app.js` 中的界面挂载、提示文本、相机参数和调试状态接口已经进入当前 ARC 主分支，本次提交补齐其依赖模块、样式、测试和说明文档。
