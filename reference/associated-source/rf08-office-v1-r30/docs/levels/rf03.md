RF-03 采用中国快递分拨中心常见的“自动供包 → DWS 扫码称重 → 摆轮分流 → 滑槽/笼车集包”顺序。任务被定义为人工异常件复核：机器人从持续运行的主线上截取三件快递，再按路由代码送入南侧镀锌笼车。

## 玩法规则

- 三件快递在传送带上持续移动，到达末端后由回流逻辑送回西端供包机。
- 一次只能携带一件快递；快递可以放在地面并重新抓取。
- 错误笼车拒绝接收，仍计作一次互动动作。
- 初始状态余量为 100。方向输入每秒消耗 3，每次互动尝试消耗 5。
- 正确投递在互动消耗后奖励 15，单次正确投递净增加 10。
- 待机和流水线自身运动不消耗状态余量，按 `R` 重置不计入消耗。
- 状态余量归零立即失败；第三件正确投递后立即通关并恢复为 100。

## 真实性基线

- 厂房开放顶尺寸为 `26.0 x 16.0 x 4.6 m`，包含混凝土地坪、保温墙板、门式钢架、电缆桥架、卷帘装卸门、电控柜、消防点和地面安全标线。
- 主输送线工作段为 `19.0 m`，带宽 `1.0 m`，带面高度 `0.82 m`；设备支腿、地脚板、侧护栏、电机和减速箱均按米制构造。
- 西端自动供包机具有封闭机壳、检修门、急停按钮和短辊筒出口，快递从这里进入主线。
- DWS 门架位于供包段之后，具备顶置扫码相机、补光条、光电传感器和称重台面。
- 摆轮段后方设置三条北向重力辊筒滑槽；南侧为人工异常件区域，使用带脚轮、网格围栏和路由牌的真实笼车。
- 三件任务纸箱分别约为 `520 x 320 x 380 mm`、`440 x 260 x 320 mm`、`580 x 380 x 420 mm`，采用瓦楞纸箱、封箱胶带、折线、面单和条码结构。

摆轮设备的模块化部署、DWS/条码识别、传感器控制、`60–80 kg` 级承载与最大 `1200 x 1000 x 800 mm` 包裹能力参考了[深圳中顺智能物流装备的摆轮分拣机资料](https://www.zssorter.com/fenjianji/8-291.html)。输送带高度和宽度同时按国内 `800 mm` 级快递站点皮带机常见规格做了游戏空间校准，未把大型交叉带环线缩成不可信的小型装置。
