# RF-09 Cardinal 真实性 Brief

## 冻结契约

- 保留两件设备的拾取、放下、按序安装、终端确认、奖励、失败条件和所有任务坐标。
- 保留第一、第三和双视角；保留现有静态碰撞契约，以及南侧入口和会议室门洞的通行契约。桌面 AV 设备复用会议桌碰撞，不保留重复碰撞体。
- 地域为中国现代企业行政办公区，正常使用状态；不使用科幻霓虹、悬浮 UI 或过度磨损。
- Cardinal 模型只作为可视资产，现有米制关卡坐标与碰撞仍为权威空间真相。

## 空间、材料与接触

- 房间 26 m × 18 m，净高 3.3 m。
- 地面使用低绒商用方块地毯的可平铺 PBR 材质，具有模块接缝、纤维方向差异和克制使用痕迹。
- 墙面使用暖白色细砂乳胶漆的可平铺 PBR 材质；会议室玻璃隔断保留独立透明材质。
- 落地家具统一使用 bottom-center pivot 和 `y=0`；桌面设备按明确支撑面放置，不能悬空。

## 处理与验收

- 请求统一使用 Y-up、+Z 正面、bottom-center pivot 和 `high-highpoly`。
- 椅子、工位、沙发、灯具只生成一个标准件并克隆；交互物所有状态复用同一个 GLB。
- 源高模先做四向隔离渲染，确认结构、贴图背景、朝向和漂浮部件，再归一化为 runtime GLB。
- 新模型仅在成功加载后隐藏程序化后备；加载失败时玩法和场景保持完整。
- 请求、task ID、哈希、尺寸、朝向、pivot 和优化参数写入 manifest；高模和生成媒体只留服务器，不进入 Git。
