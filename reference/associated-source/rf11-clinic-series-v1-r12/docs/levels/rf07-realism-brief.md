## 场景基调

场景是中国正常运行中的 BSL-2 生物实验室冷链转运区，不是展厅、废弃空间、灾后场景或科幻实验室。建筑和设备以近十年常见的洁净实验室为基准：

- 浅灰无缝环氧自流平地坪，低光泽，有极轻微清洁拖痕、轮迹和真实粗糙度变化。
- 暖白色可擦洗洁净墙板，竖向拼缝、圆弧阴角和耐化学品踢脚，不使用纯白无纹理盒体。
- 304 拉丝不锈钢、粉末喷涂钢板、黑色酚醛树脂台面、安全玻璃和医用 ABS 形成克制的真实材料层次。
- 磨损集中在脚轮、把手、工作台前缘、设备底部和高频接触区；不做全表面随机脏污。
- 照明为中性偏冷实验室环境光与柔和定向补光，不增加霓虹、过强 Bloom 或悬浮 UI。

## 朝向、缩放与落地门

每个源 GLB 必须经过隔离预览和四向检查后才能进入 runtime：

1. 记录原始 AABB、主轴、最低点和可识别正面。
2. 在子节点上修正正面到 `+Z`，再在未旋转父节点上做米制尺寸拟合。
3. 水平中心归零，最低点归一到 `y=0`，底部中心作为 pivot。
4. 导出后重新测量，尺寸误差不得超过目标值的 `2%`。
5. 场景摆放后检查 `worldMinY` 与支撑面高度，允许误差 `0.005 m`；超差时测试和构建失败。
6. 靠墙设备记录背面与墙面的净距；不得穿墙，也不得用阴影掩盖悬空。
7. 交互资产的地面、手持、箱内和交付状态必须复用同一已归一化模型，不单独补偿旋转或缩放。

## 加载与后备

- Cardinal runtime GLB 成功加载后才隐藏对应程序化后备。
- 同一 URL 只加载一次；BSC、转运车、冷藏柜、样本盒和废物桶使用克隆。

- Cardinal 模型不参与碰撞计算，现有可达性测试继续作为权威玩法门。
