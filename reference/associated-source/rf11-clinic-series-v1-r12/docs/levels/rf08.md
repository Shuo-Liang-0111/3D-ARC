# RF-08 办公室灰盒

RF-08 当前为自由探索灰盒，用于先确认用户提供的 3DGS 扫描场景布局。损坏的 Gaussian-to-surfel GLB 已停用并从运行目录删除；本阶段不加载任何 Gaussian、PLY、SOG 或 GLB 环境。

## 布局基准

- 房间尺寸：`6.6m × 3.8m × 2.9m`，长轴为东西方向。
- 西侧：玻璃隔断、铝合金框架和入口门洞。
- 中央：四列、两排背靠背白色工位，共八个座位。
- 两侧：连续通道、八把办公椅、两台落地风扇和三个垃圾桶。
- 工位附件：显示器、笔记本、主机、键鼠、抽屉柜、水瓶。
- 房间附件：东侧储物柜、饮水机，西北角纸箱。

## 当前运行规则

- Unitree G1 从西侧入口内侧开始，自由行走，无任务和交互。
- 移动仅保留极低的统一状态余量消耗，场景不会失败或自动完成。
- 房间边界、中央桌组、办公椅、风扇、储物柜、饮水机和纸箱具有基础碰撞。
- 相机以俯视布局核对为优先，同时保留第一人称和双视角。

确认灰盒布局后，再以该坐标系为基准接入正确的 3DGS 视觉层或逐步替换高质量 GLB 家具。
