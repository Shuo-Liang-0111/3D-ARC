# RF-14 球车与裁判椅布局修正

用户指出 `realism-v0.4.4` 出现两辆球车，裁判椅摆放不对。

`realism-v0.4.5` 移除额外装饰储球车及其碰撞和加载项，仅保留东侧 `(8.2, 8)` 的归筐球车。裁判椅移到西侧球网端部 `(-7.35, 0)`，绕 Y 轴旋转为 `+π/2`，使座椅正面朝向场内 `+X`，沿球网方向观察两边场地。此前 `-π/2` 导致椅子朝向场外。

椅子模型与碰撞同步，距离西侧网柱包围盒约 0.25 m；椅背后至围栏保留约 1.98 m 的通路，持球机器人可沿 `x=-8.9` 往返绕行。已移除球车的位置可正常行走，不遗留空气墙。原有归筐坐标和八球玩法保持一致。

资产通过 `node tools/rf14-fix-layout.mjs --source realism-v0.4.4 --revision realism-v0.4.5 --chair-x=-7.35` 复制到独立版本，旧版本资产保持原样。脚本同步碰撞 GLB、manifest 和哈希；裁判椅位置/朝向由 `UMPIRE_CHAIR` 供场景和碰撞定义共用。

验证记录在 `production/rf14/realism-v0.4.5`，覆盖完整引擎路线、持球绕椅、碰撞节点完整匹配、实际椅子模型与碰撞尺寸、source/build/served 资产哈希以及正式浏览器画面与归筐路线。验收结果以该目录最终报告为准。
