# RF-10 按钮移除与火灾时限 · rf10-fire-v4

## 本次行为

RF-10 / RF-10-2 / RF-10-3 共用厨房移除水槽旁和燃气炉旁的附加按钮及外壳。
实际燃气旋钮、模型资产、碰撞布局和中等关卡原有交互规则沿用。
第一视角显示天花板，第三视角隐藏天花板及天花灯具。

RF-10-3 从着火瞬间独立计时：60 秒内未扑灭，立即失败并锁定移动与互动。
HUD 显示灭火剩余秒数，失败弹层明确说明“着火后 60 秒内未能灭火，任务失败。”
静止和延迟帧均推进计时；跨过点火阈值的帧余量计入灭火时限。
失败后迟到的灭火交互无法恢复任务。

灭火以正式喷射完成事件提交。火扑灭时停止倒计时，随后播放放瓶动作；
自动放瓶不重复扣除灭火交互余量。灭火后仍须取壶、重新装水、放壶并重新加热。
原 55–65 秒关火窗口和提前关火重烧规则保持不变。
