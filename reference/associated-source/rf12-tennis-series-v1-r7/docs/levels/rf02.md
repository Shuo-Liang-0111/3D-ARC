RF-02 在原有米制写实图书馆基础上完成了 Cardinal 真实化。玩法、布局、碰撞和双视角契约保持不变；入口防盗门、总服务台、目录终端、中央还书整理台、还书车、室内绿植、悬挂式线性灯具、阅览桌椅和红色任务书使用 Cardinal 高模转制的 runtime GLB。地板使用 Cardinal 生成的 2K 暖浅灰水磨石材质，精确建筑壳体和书架继续使用服务器 Blender 米制方案。

## 真实尺度布局

- 单层市级公共图书馆开架借阅与阅览厅：`24.0 x 16.0 m`，室内净高 `3.6 m`。
- 南侧入口净宽 `2.0 m`，入口内设置两组防盗检测门，中央通行净宽大于机器人通行需求。
- 读者动线为：入口 → 防盗检测门 → 总服务台/目录终端 → 中央还书整理台 → 开架书架/阅览区。
- 成人开架书架为 `3.0 x 0.58 x 1.8 m`，五层有效架板；主通道按 `1.5 m` 组织，架间净距不低于 `1.2 m`。
- 阅读桌为 `2.4 x 1.05 x 0.75 m` 四人桌，椅面高 `0.47 m`，桌面配置集中电源盒。
- 总服务台高台面约 `1.07 m`，含一段约 `0.78 m` 的无障碍低位台面；目录终端高约 `1.35 m`。
- 馆内包含还书车、垃圾分类站、消防柜、绿植、新风/空调格栅、CCTV、窗台和线性灯具等尺度参照物。

三本精装书均约为 `172 x 245 x 41 mm`，使用底部中心枢轴。红书在桌面、手持、落地和归位状态复用同一个 Cardinal GLB；黑、白书暂时保留已验证的米制 GLB。还书台台面高度为 `0.78 m`，交互书的桌面状态以该高度放置，避免悬空。书架本体不随状态移动，因此属于静态环境。

两张 `2.4 x 1.05 x 0.75 m` Cardinal 阅览桌位于 `[-5.0, 0, 2.35]` 与 `[5.4, 0, 2.35]`；每桌四把 `0.52 x 0.55 x 0.88 m` 椅子按长边两侧各两把摆放。Blender 顶点分析确认 Cardinal 椅背位于模型原点的 `-X` 侧，因此实际坐姿前向为 `+X`；南侧椅子旋转 `-π/2`、北侧椅子旋转 `+π/2`，使八把椅子的座面朝向桌面、椅背位于外侧。

地板材质来自 Cardinal 图像任务 `aigc_e838989a1db147f5a3461f5f3188e295`，以 2K 无缝漫反射图嵌入静态壳体。运行时使用低对比暖灰细缝，避免旧版深色粗网格破坏公共图书馆的真实尺度感。

Cardinal 请求使用服务器安装的官方 helper 提交，源高模保存在 `models/source`，运行时版本使用 glTF Transform `4.4.2` 完成米制归一化、底部中心 pivot、简化、Draco 和 WebP 转制。静态壳体由 Blender 通过 `--omit-cardinal-slice` 重建，剔除两批 Cardinal 物体的旧合并网格，保证新旧资产不会重叠。

## 玩法保留

- 红、黑、白三本书从中央还书整理台依次拾取，一次携带一本。
- 三处目标书架位于西、北、东三个馆藏方向，错误书架拒绝归位。
- 书可以在可通行地面放下并重新拾取。
- 每本首次正确归位补充 18 点任务余量，三本全部归位后立即完成。
- 第一、第三和双视角、WASD、E 互动及目录终端状态保持不变。

## 验收要求

- 状态机、碰撞、入口净空、所有任务点可达性通过专项测试。
- Cardinal 壳体、九类静态切片和红书的尺寸、哈希、内嵌贴图、Draco 和总下载预算由清单测试锁定。
- 第一、第三和双视角必须完成固定路线截图检查，红书四种状态外观一致。
- Vite 生产构建必须通过。
