# RF-12 真实性 Brief

## 场景

正常使用的中国城市家庭开放式厨房，约 8.4 m × 6.8 m，层高 2.8 m，Y 轴向上。浅灰防滑瓷砖地面、浅色釉面墙砖、木纹橱柜、石英石台面、不锈钢灶具和冰箱；日间窗光配合冷白顶灯，灶台墙面有轻微油烟痕迹但保持整洁。

## 玩法冻结

单台 Unitree G1 读取冰箱旁备餐卡，依次摆放番茄篮、豆腐盒和食用油瓶，将平底锅放到指定炉头，先开油烟机再开炉头并等待 8 秒计时。计时结束后关闭炉头和燃气总阀，把平底锅移到隔热垫，回到入口终端提交确认。奖励、失败、余量和交互规则由 `engine.js` 管理。

## 真实化约束

Cardinal 只生成可视环境和独立器具；`rf12_collision.glb` 是权威隐藏碰撞层。地砖和墙砖必须连续贴合，不出现拉伸接缝；冰箱、橱柜、灶台和油烟机必须靠墙或落地。平底锅底部贴炉架/隔热垫，油瓶和食材容器底部贴台面，所有模型正面朝 `+Z`，禁止附带机器人、手、额外地面、悬浮部件、文字 Logo 或烘焙灯光。
