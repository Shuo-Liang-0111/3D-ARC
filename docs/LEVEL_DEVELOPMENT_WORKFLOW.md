# 关卡开发流程入口

本文件只用于兼容历史链接，不再维护第二套生产标准。

所有关卡的唯一生产、资产命名、真实性验收和冻结规则见：

- [WEB_LEVEL_PRODUCTION_PIPELINE.md](WEB_LEVEL_PRODUCTION_PIPELINE.md)

执行时必须特别遵守：

- RF-04 v3 是可复现参考实现，不是家庭或仓库布局模板。
- 每关重新填写主题无关的空间与资产简报。
- 整体不可交互环境与每个可交互物分别生成。
- EmbodiedGen 失败或人工视觉验收未通过时，状态只能是“玩法完成、视觉未完成”。
- 程序化回退必须命名为 `graybox_baseline`，禁止命名或冻结为 `final`。
- 单元测试、GLB 可加载和碰撞正常不能替代真实性验收。
