# RF-15 农产品冷链装运

清晨的中国乡镇合作社半开放仓库。领取番茄、苹果采摘筐，逐筐称重并记录，在包装台封箱贴签，再通过冷藏车尾板装车。两箱都进入车厢后返回南侧出库台确认。

操作沿用 ARC：W/S 前后、A/D 平移、Q/E 转向、方向键上下调整 D435、F 交互、R 重置。第一视角需使用正常抬头操作观察前方；第三与双视角使用现有 ARC 操控面板。机器人、骨骼、共享运动与镜头文件均保持基线字节。

番茄 8.6 kg、苹果 9.4 kg 是任务模拟数据。纸箱标签与称重记录使用同一数据源。场景包含收货台、电子秤、包装工位、尾板控制器、冷藏车、出库台、周转筐、搬运车及农田背景。

资产版本 `realism-v0.2.6`；四件 Cardinal 道具采用 high-highpoly 生成并做米制归一化。建筑、货车、纸箱及权威碰撞由 Blender 生成，地面复用 Poly Haven CC0 材质，树木复用 RF-14 既有资产。详见 `rf15-asset-manifest.json`。

预计人工体验 3–5 分钟；引擎最短路线约 75 米。人类通关时间尚未做独立计时实验，不能用自动路径的模拟时间替代。
