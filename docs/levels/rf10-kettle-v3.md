# RF-10-3 烧水任务 · rf10-kettle-v3

## 发布范围

选关编号 RF-10-3 对应运行时路由 `rf12-3`。任务改为：
取水壶 → 装水 → 放到炉头 → 点火 → 在 55–65 秒内关火。
不包含油烟机、平底锅或安全巡检前置任务。

提前关火保留壶内水量，重新点火从零计时。
超过 65 秒着火并使水量失效；灭火后必须从炉头取壶、重新装水、放回并重新点火。
55、65 秒边界均包含；开关火在正式手部接触事件提交，环境计时独立于移动帧。

RF-10 / RF-10-2 / RF-10-3 共用同一套厨房、碰撞、道具、水壶和水槽。
第一视角显示天花板，第三视角隐藏天花板和天花灯具。机器人模型、关节数据、
共享移动及相机合同未修改。
