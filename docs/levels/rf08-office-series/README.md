# RF-08 办公室系列

正式版本为 `rf08-office-v1-r18`。页面 RF-08 对应内部路由 `rf09`，扫描办公室 `rf08` 不属于本任务。

| 页面 | 内部路由 | 完成要求 |
| --- | --- | --- |
| RF-08 会议准备 | rf09 | 在会议桌摆好一份文件和一瓶水 |
| RF-08-2 通道整理 | rf09-2 | 将入口挡路椅子推到会议桌前，再摆好一份文件和一瓶水 |
| RF-08-3 会务来电 | rf09-3 | 完成第二关要求，并在来电后 30 秒内接听电话 |

三关共享同一场景、家具和装饰物集合。第一关的椅子预先停好，第二、三关将同一把椅子放在会议室入口。入口玻璃扩展为 1.4 m 净开口，视觉结构与碰撞采用相同尺寸；椅子放在入口时机器人无法从两侧挤过。玩家靠近按 F 扶住椅背，用移动键推到会议桌前的黄色地面框，按 F 松开；不自动移动椅子、不吸附归位。其余桌前椅子稍向桌内收拢，以保留携物通行净空。

文件与水统一放在前台工作台，会议桌上只保留一组目标标记。原来的三件物品归还、四席摆放、打印配送、补给、资料回收与最终终端确认不再是任务，也不再干扰 F 候选选择。旧道具作为共同场景装饰保留。

第三关在第一件物品成功摆放后响铃一次。会议桌旁的办公电话显示来电和剩余秒数，HUD 显示同一倒计时，并播放双音铃声。靠近按 F 操作免提按钮，手部接触后提交接听；携物时使用空闲左手。到 30 秒仍未接听则直接失败，即使两件物品已经摆好。电话使用单调时钟真实经过时间；低帧率和后台渲染节流不会延长倒计时，交互提交前再次核对期限。重置会恢复全部任务及来电状态。

第一人称显示天花板和灯具，第三人称隐藏。G1 模型、骨架、初始姿态数据、D435、共享相机、控制映射、MuJoCo 速度策略和 r14 的余量规则保持不变：初始/上限 100，平移消耗 1.2 点/秒，F 交互 4 点，原地转向和静止免扣。任务物品首次拾取奖励 10 点，正确摆放及椅子归位奖励 14 点，按任务目标只奖励一次。自动取放采用既有碰撞允许的短程迈步和关节动画，最终动作恢复站立后再结算。

## 资产与代码

办公室复用已验收的 Cardinal 家具及墙地面材质。打印机继续使用原 Blender 精确模型。新增电话为 `office-phone.js` 的精确程序模型：独立听筒、底座、支架、键盘、扬声器缝、螺旋线缆、屏幕、指示灯和免提按钮。三关均加载同一电话，任务状态仅决定是否响铃。没有新下载的二进制依赖。

- `office-layout.js`：共同建筑碰撞、物品、任务席位、挡路椅与目标坐标。
- `office-engine.js`：取放、推椅、任务状态、余量、电话截止时间与失败。
- `office-clock.js`：真实时间适配，支持低帧率及后台更新。
- `office-animation.js`：复用既有手臂和迈步接口；按接触点提交。
- `office-qa.js`：仅 `?qa=office` 加载的定点验收夹具。

## 验证与发布

工作区与环境均在用户指定的 `/path/to/arc-workspace` 下。项目为 `.`，生产记录为 `./authoring/server-production/rf08-office-v1`。Mac 只用作控制和截图证据保存。

```sh
node --test tests/rf08-office-series.test.mjs tests/rf08-office-motion-reserve.test.mjs
node --test --test-name-pattern='RF-09 is registered' tests/rf09-office.test.mjs
node tools/rf08-office/build-candidate.mjs rN
```

构建目录不可覆盖；通过后由 Vite middleware 将三个正式入口切换到同一版本。共享 `dist` 使用 Vite `build({build:{emptyOutDir:false}})` 验证，避免清理其他工作正在写入的文件。

当前 18 项状态/动作/碰撞/运动/计时测试通过，包括：两物品任意顺序、只选择新任务道具、椅子前后真实通行差异、共享推行速度、30 秒边界、后台时间累计、接听及超时分支、重复奖励防护、重置和原有余量规则。浏览器通过定点布置机器人站位，再播放正式动作；不移动道具、不直接写完成状态。这不代表完整路线导航或通关余量预算测试。实际候选记录与截图存放于生产目录 `simple-tasks/`、`evidence/browser/`。


浏览器验收结果：r18 第一关只执行文件拾取/摆放、水拾取/摆放四次正式交互，即在恢复站立后完成。r16 第三关接听成功链 10 步通过，接听按钮提交误差 0.000417 m；r17 超时链 8 步通过，倒计时截止后约 7 ms 进入失败，余量仍为 100，弹窗明确提示电话超时。r18 与 r17 的办公室玩法模块及三个入口在规范化构建文件名后字节一致，仅隔离 QA 增加观察站位和已有 D435 低头输入。第一视角的电话、按钮、线缆及支撑面已实际查看；第三视角入口挡椅及通道已实际查看。定点验收完成了真实动作和局部碰撞，不构成完整路线通关测试。
