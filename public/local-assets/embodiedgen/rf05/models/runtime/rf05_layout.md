# RF-05 realistic hotel room asset layout
- Room shell: 8.4m x 10.8m x 2.8m, south entry clear width 1.3m.
- Bathroom: entry-side 3.0m x 3.3m wet room with vanity, mirror, shower tray, room-side partition wall and glass return.
- Twin beds: two 1.86m x 2.65m beds on the north wall with shared nightstand.
- East wall: work desk, chair, television console, wardrobe and luggage bench.
- Environment and six interactive GLBs are generated independently. Interactive source models are SAM3D outputs normalized to meter scale with bottom-center pivots.
